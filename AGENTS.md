# Instrucciones del proyecto

- Antes de trabajar en este repositorio, lee [`PROMPT_MAESTRO.md`](./PROMPT_MAESTRO.md) y [`PLAN_TRABAJO_SG_SST.md`](./PLAN_TRABAJO_SG_SST.md).
- Usa el plan como contexto de continuidad entre sesiones: revisa el estado actual del código y pruebas, retoma el siguiente criterio pendiente y actualiza el registro al cerrar una fase.
- No confundas pantallas o endpoints existentes con flujos aceptados; verifica persistencia, permisos y pruebas.
- No marques cumplimiento normativo ni uses datos reales sensibles sin confirmación de la empresa, fuentes vigentes y revisión SST que corresponda.
- Conserva el español de Colombia en la interfaz y documentación. Para cambios de código sigue las convenciones del repositorio y ejecuta las validaciones pertinentes.
